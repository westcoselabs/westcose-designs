# Local brand fonts

Manrope Latin variable weights 400–700 and Oswald Latin variable weights 600–700 are bundled to remove the Google Fonts build-time resolver/network dependency. Font family CSS variables are unchanged.

Downloaded from the official Google Fonts CSS API on 2026-10-06. Both fonts are distributed under the accompanying SIL Open Font License files, sourced from google/fonts (`ofl/manrope` and `ofl/oswald`).

- Manrope: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- Oswald: https://fonts.gstatic.com/s/oswald/v57/TK3IWkUHHAIjg75cFRf3bXL8LICs1_Fv40pKlN4NNSeSASz7FmlWHYg.woff2
